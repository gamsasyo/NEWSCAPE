NEWSCAPE 초대 페이지 — 참석 명단(RSVP) 설정 안내
================================================

초대 페이지에서 "참석합니다"를 누르면 이름과 연락처가
NEWSCAPE 구글 계정의 스프레드시트에 자동으로 한 줄씩 쌓입니다.
명단은 그 시트를 열면 바로 보입니다. 별도 서버나 프로그램은 없습니다.

  [초대 페이지 "참석합니다"]
          │  이름·연락처
          ▼
  [Apps Script 웹 앱]   ← NEWSCAPE 구글 계정 소유
          │
          ▼
  [구글 시트 "NEWSCAPE RSVP"]   ← 명단은 여기서 확인

한 번만 아래 설정을 해 주시면 됩니다. (약 10분)
설정이 끝나면 마지막에 나오는 "웹 앱 URL" 하나만 신재영에게 보내 주세요.


준비
----
- newscape515@gmail.com (또는 명단을 관리할 NEWSCAPE 계정)으로 로그인
- 다른 구글 계정이 같은 브라우저에 로그인돼 있으면 섞일 수 있으니,
  시크릿 창(비공개 창)을 열어 NEWSCAPE 계정 하나만 로그인한 상태에서 진행 권장


1. 스프레드시트 만들기
----------------------
구글 드라이브 → 새로 만들기 → Google 스프레드시트
파일 이름: NEWSCAPE RSVP


2. Apps Script 열기
-------------------
시트 상단 메뉴  확장 프로그램 → Apps Script
(새 탭에 코드 편집기가 열립니다)


3. 코드 붙여넣기
----------------
편집기에 기본으로 들어 있는 내용(function myFunction() { ... })을 전부 지우고,
함께 보내 드린 Code.gs 파일의 내용을 통째로 붙여넣습니다.
저장: Ctrl+S (Mac은 ⌘S)


4. 웹 앱으로 배포
-----------------
편집기 오른쪽 위 파란 버튼  배포 → 새 배포

  유형 선택(왼쪽 톱니바퀴)  : 웹 앱
  설명                     : rsvp v1
  실행 주체                : 나 (newscape515@gmail.com)
  액세스 권한              : 모든 사용자
  → 배포


5. 권한 승인 (여기가 조금 헷갈립니다)
------------------------------------
"액세스 승인" 버튼 → 계정 선택 (newscape515)
→ "Google에서 확인하지 않은 앱입니다" 라는 경고 화면이 뜹니다
→ 왼쪽 아래 작은 글씨  "고급"  클릭
→ "NEWSCAPE RSVP(안전하지 않음)(으)로 이동"  클릭
→ 허용

이 경고는 구글의 정식 심사를 받지 않은 개인용 스크립트에 항상 뜨는 것으로,
방금 직접 만든 스크립트이므로 문제 없습니다.


6. 웹 앱 URL 복사 → 전달
------------------------
배포가 끝나면 아래 형태의 주소가 나옵니다.

  https://script.google.com/macros/s/AKfy.............../exec

이 주소를 복사해서 신재영에게 보내 주세요.
(초대 페이지에 이 주소를 연결하는 작업은 신재영이 합니다)

확인 방법: 그 주소를 브라우저에 붙여넣어 열었을 때
  {"ok":true,"service":"newscape-rsvp"}
가 보이면 정상입니다.


이후 명단 확인
--------------
시트 "NEWSCAPE RSVP" 의 RSVP 탭에 실시간으로 쌓입니다.

  제출시각          | 성함   | 연락처       | 기기
  2026-10-01 14:02  | 홍길동 | 01012345678  | iPhone …

- 연락처는 텍스트로 저장되어 앞자리 0이 사라지지 않습니다.
- 시트는 NEWSCAPE 계정 소유이므로 다른 사람은 볼 수 없습니다.
  신재영이 명단을 봐야 할 경우 시트 공유를 해 주시면 됩니다.


참고: 나중에 수정이 필요할 때
-----------------------------
스크립트를 고친 뒤에는  배포 → 배포 관리 → 연필 아이콘 → 버전: 새 버전 → 배포
로 하면 주소가 그대로 유지됩니다.
("새 배포"를 누르면 주소가 바뀌어 초대 페이지 연결을 다시 해야 합니다.)
